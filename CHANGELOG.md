# Changelog

All notable changes to the Gaming Platform will be documented in this file.

## [1.0.0] - 2024-01-XX

### Added
- Initial release of Gaming Platform
- Complete backend API with NestJS
- Frontend with Next.js 14
- Authentication system (JWT, 2FA, OTP)
- Multi-currency wallet system (INR, USDT, BTC)
- Ledger-based transaction system
- Provably fair games (Dice, Crash, Mines)
- Payment gateway integration (Razorpay, Crypto)
- Bonus and promotion system
- Admin panel with role-based access
- KYC/AML compliance features
- Fraud detection framework
- Comprehensive documentation

### Features
- User registration and login
